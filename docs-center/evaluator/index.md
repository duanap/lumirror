# 参与者指南

## 进入评价

常规活动通常使用两段式入口：

1. 打开活动的随机邀请链接。
2. 输入分配给你的数字邀请码。
3. 系统校验后加载当前待评价任务。

部分活动也会使用一次性时效链接，首次打开后开始有效期倒计时。

## 完成任务

每次页面聚焦一个评价目标。成员评价可展示成员基本信息，团队整体评价展示团队信息；两种目标不会混在同一个评分语义里。

评分维度由活动配置决定。系统会校验每个维度的允许分值，并根据当前活动真实规则计算综合分。

## 进度

参与者只应看到自己的任务进度，例如：

```text
已完成 3 / 8
剩余 5
```

进度信息不能用于推断其他评价人的身份或评分内容。

## 完成后

全部任务提交后进入完成状态。公开端不提供个人评分结果查询。

## 匿名原则

参与评价时请不要在自由文本或其他可识别内容中主动填写评价人身份信息。系统层面也不会通过公开进度接口返回 evaluator identity。
