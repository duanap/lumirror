# 管理员概览

后台管理覆盖组织、成员、评价、任务、结果和系统设置。

## 组织与成员

- 部门
- 团队
- 成员
- 成员多标签
- 岗位与启停状态

推荐的后台导航顺序是：部门 → 团队 → 成员。

## 评价管理

- 评价周期
- 评价活动
- 参与者范围
- 目标范围
- 评分维度和计分规则
- 邀请码与时效链接
- 评价任务
- 活动归档与恢复

## 结果与趋势

结果页展示活动产生的评分汇总。趋势看板按时间范围查看员工或团队历史变化，并包含已归档活动。

## 权限

账号角色包括 `admin`、`team_leader`、`leader` 和 `member`。R2 架构迁移不得改变现有 RBAC 语义。
