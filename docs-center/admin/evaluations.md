# 评价活动

## 创建活动

创建活动前先选择有效的评价周期。活动开始时间和结束时间必须完整落在周期边界内，已结束周期不能用于新活动。

成员评价目标可以来自：

```text
指定团队成员
整个部门成员
自定义成员
```

这些只是目标范围选择方式，最终任务目标仍为 employee。

团队整体评价使用：

```text
targetType = team
```

## 参与者与目标分离

参与者范围决定“谁来评价”，目标范围决定“评价谁”。两者必须独立处理。

当 `excludeSelf` 启用时，成员不应获得评价自己的任务；inactive employee 不应生成新任务。

## 归档

只有已经结束的活动可以归档。

归档后：

- 活动只读
- 历史评分保留
- 历史任务保留
- 邀请码保留
- 时效链接保留
- 历史趋势保留
- 可以恢复归档

归档不是删除，任何实现都不能把两者混为一谈。
