# v1.5.1

v1.5.1 是安全依赖和 CI 基线版本。

## 完成内容

- `nanoid` 安全升级
- `postcss` 安全升级
- `npm audit = 0 vulnerabilities`（发布 Gate 时）
- GitHub Actions CI
- Node 22 CI
- npm cache
- API / Server / Build 自动 Gate

## 不包含

v1.5.1 本身不包含：

- Observability
- Repository
- R2 Direct SQL
- E2E
- Schema migration

Backend R2 的评分链是在 v1.5.1 基线上后续完成并合并。

## Schema

SQLite Schema Version 保持为：

```text
4
```

没有为了 R2 主动升级 schema。
