# v1.5.1

v1.5.1 是安全依赖和 CI 基线版本。

## 发布状态

截至 2026-09-07，v1.5.1 已合并并打 Git 基线，但当前生产仍运行 v1.5.0。v1.5.1 以及其后合并的 Backend R2 评分链都不能据此视为已经生产发布。

## 完成内容

- `nanoid` 安全升级
- `postcss` 安全升级
- `npm audit = 0 vulnerabilities`（发布 Gate 时）
- GitHub Actions CI
- Node 22 CI
- npm cache
- API / Server / Build 自动 Gate

## 不包含

v1.5.1 本身不包含：

- Observability
- Repository
- R2 Direct SQL
- E2E
- Schema migration

Backend R2 的评分链是在 v1.5.1 基线上后续完成并合并，但仍未部署生产。

## Schema

SQLite Schema Version 保持为：

```text
4
```

没有为了 R2 主动升级 schema。
