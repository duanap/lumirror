# 匿名边界

匿名评价不是只隐藏一个姓名字段，而是要求所有公开接口、日志和后台进度都避免形成可反向识别评价人的信息链。

## 公开评价端

公开端可以展示：

- 当前评价目标
- 当前参与者自己的任务数量
- 已完成数量
- 剩余数量
- 时效链接状态

公开端不能展示：

- 其他评价人身份
- 个人评分结果
- 可以还原其他参与者状态的敏感信息

## 日志

结构化日志禁止记录：

```text
password
Authorization
Cookie
session
完整邀请码
完整 timed invite link
个人评分内容
```

## 邀请码

长期存储应采用 hash、fingerprint、mask 等形式。完整邀请码只允许在生成时返回一次，不写入日志。
