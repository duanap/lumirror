# 开始使用

Lumirror 主要有两类使用入口：公开评价端和后台管理端。

## 公开评价端

评价参与者通过活动邀请进入系统。根据活动配置，参与者可能使用随机邀请链接加邀请码，也可能使用一次性时效链接。

公开端只展示当前参与者需要完成的任务和进度，不展示个人评分结果，也不应暴露其他评价人的身份。

## 后台管理端

后台用于维护组织结构、成员、评价周期、活动、任务、结果和趋势。账号角色包括：

- `admin`
- `team_leader`
- `leader`
- `member`

成员标签只用于标记和筛选，不参与 RBAC。
