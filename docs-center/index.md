# Lumirror / 和光镜鉴

**匿名反馈 · 公平成长。**

Lumirror 是面向企业和团队的匿名评价系统。它把评价参与、评价目标、评分任务、结果汇总和后台权限分离设计，在保留匿名边界的同时，让组织可以持续追踪成员与团队的历史表现。

从邀请链接、邀请码或时效链接进入评价，完成分配给自己的任务，并了解进度与有效期。

## 先理解这几条规则

- **成员评价和团队整体评价是两种独立评分语义。** 团队趋势只能使用 `target_type = team` 的团队整体评分，不能用成员平均分替代。
- **参与者范围和评价目标范围互相独立。** 部门可以用于选出成员目标，但最终评分目标仍然是 employee。
- **归档不是删除。** 已归档活动保持只读，历史评分、任务和趋势继续保留，并允许恢复归档。
- **成员标签不是 RBAC。** 标签只用于元数据和筛选，不改变账号权限。
- **匿名边界优先。** 公开评价端不能泄露评价人身份或个人评分结果。
